# 자유글 시선측정이란?

시선추적기반 읽기능력 진단(Reading) 기능은 미리 등록된, 정해진 형식의 글에 대해서만 진단이 가능합니다. 한 페이지에, 그림도 없고 글자 크기나 문서의 형태도 일률적입니다.

하지만 다음과 같은 다양한 문서에 대한 시각적 탐색이 필요할 때가 있습니다.

* 여러 페이지로 구성된 기출시험문제지
* 도표, 이미지, 지도 등이 포함된 글이나 문제
* e-Book 형태의 책
* 그림 또는 그림책

**자유글 시선측정**은 관리자가 원하는 PDF 문서를 등록하면, 학생이 그 문서를 읽는 동안의 시선을 측정하고 보고서로 보여 주는 기능입니다. 다음과 같은 문서를 지원합니다.

* PDF 파일 형식만 가능
* 최대 25쪽까지의 PDF 문서만 가능
* 문서 위에 영역(글, 그림, 질문, 보기 등)을 지정하고, 문제를 설정할 수 있음
* 결과 보고서 제공

{% hint style="info" %}
기존 \[자유글] 탭과 별개로, \[자유글2] 탭에서 새 방식의 자유글을 등록하고 결과를 봅니다. 사용할 수 있는지는 기관의 플랜에 따라 다릅니다.
{% endhint %}

## 어떻게 진행되나요?

1. 관리자가 \[자유글2] 탭에서 PDF 문서를 등록하고, 글과 문제의 영역을 지정합니다. ([자유글 문서 등록하기](new_free_pdf.md))
2. 학생이 키오스크에서 문서를 선택하고, 시선 보정을 한 뒤 문서를 읽습니다. 문제가 있는 문서라면 문제도 풉니다.
3. 측정이 끝나면 결과 보고서가 만들어지고, 관리자는 결과 목록에서 보고서를 확인하거나 학부모, 교사에게 링크를 보낼 수 있습니다.

## 진단 결과는 어떻게 제공되나요?

결과 보고서는 요약 화면과 쪽 화면으로 구성됩니다.

### 요약 화면

* **AI 총평**: 맨 위에 \[현재 읽기 상태], \[학업에 미치는 영향], \[지도해야 할 방향]을 쉬운 말로 정리합니다. 진단명이나 원인을 단정하지 않습니다.
* **읽기능력 점수와 등급**: 같은 문서를 읽은 또래와 견주어 0~99점의 점수와 우수, 양호, 주의, 미흡 등급으로 보여 줍니다.
* **지표 카드**: 읽기 상태를 세 영역으로 나누어 지표별로 보여 줍니다. 지표마다 내 값과 또래 값, 적정 범위를 한 줄 띠로 비교할 수 있습니다.

| 영역 | 지표 |
|---|---|
| 이해 | 문제 정답률, 문제풀이 시간, 선택지 영역 평균 방문 횟수 |
| 유창성 | 읽기 속도, 글 영역 평균 응시 시간, 글 영역 평균 도약폭 |
| 읽기 전략 | 빠짐없이 읽은 비율, 글 영역 평균 방문 횟수, 글 영역 시선 점유율 |

* **시선 분포**: 학생의 시선이 글, 그림, 기타, 질문, 오답, 정답, 영역 밖 중 어디에 얼마나 머물렀는지 막대와 표로 보여 줍니다.
* **문제 정답률**: 문제별 정답과 오답, 풀이 시간을 보여 줍니다.

{% hint style="warning" %}
같은 문서를 읽은 또래 기록이 **20명 미만**이면 읽기능력 점수와 등급을 내지 않고 \[데이터 부족]으로 표시합니다. 이때 지표는 또래 대신 연령과 언어별 임시 기준과 비교하며, 그 안내 문구가 함께 표시됩니다. 한 번 정해진 점수는 바뀌지 않고, 결과 목록에서 \[재분석]을 누를 때만 다시 계산됩니다.
{% endhint %}

### 쪽 화면

요약 화면 오른쪽 위의 \[쪽별 시선 재생] 버튼으로 엽니다. 학생이 문서를 읽은 과정을 **있는 그대로 기록해서 재생**합니다.

* 학생이 쪽을 오간 순서 그대로, 시선(응시와 도약)을 시간 순서대로 재생할 수 있습니다.
* \[시선] 보기에서는 응시와 도약을, \[이동] 보기에서는 영역 사이를 오간 흐름을 볼 수 있습니다.
* 영역별 점유율, 응시 횟수, 시간을 확인할 수 있습니다.
* 문제가 있는 문서에서는 학생이 고른 보기와 정답, 오답이 영역에 표시됩니다.

자세한 사용법은 [자유글 시선측정 결과 보기](result_pdf.md)를 참고하세요.

## 읽기진단(Reading)과 무엇이 다른가요?

읽기진단은 **미리 등록된, 조건이 통제된 지문**을 사용하므로 단어 단위의 정밀한 분석이 가능합니다. 자유글은 사용자가 올리는 자유로운 형식의 문서이므로 다음과 같은 차이가 있습니다.

* 시선이 닿은 곳을 단어 단위가 아니라 관리자가 지정한 **영역 단위**로 분석합니다.
* 읽기능력 점수는 **같은 문서를 읽은 또래와의 비교**로 정해지므로, 문서를 읽은 또래 기록이 쌓여야 점수가 표시됩니다.
* 이해 지표는 문서에 문제를 설정한 경우에 의미가 있습니다.

{% hint style="info" %}
학생이 문서를 **어떤 방식으로 탐색하는지** 눈으로 확인하고 싶다면 자유글 시선측정을, 정해진 지문으로 정밀한 읽기능력 분석을 원한다면 읽기진단(Reading)을 이용하세요.
{% endhint %}
