# 자유글 시선측정이란?

시선추적기반   읽기능력  진단 (Reading) 기능으로는 미리 등록된, 정해진 형식의 글에 대해서만 진단이 가능합니다. 한 페이지에, 그림도 없고 글자 크기나 문서의 형태도 일률적입니다.

하지만 다음과 같은 다양한 문서에 대한 시각적 탐색이 필요할 때가 있습니다.&#x20;

* 여러 페이지로 구성된 기출시험문제지
* 도표, 이미지, 지도 등이 포함된 글이나 문제
* e-Book 형태의 책
* 그림 또는 그림책

원하는 문서를 리더스아이를 통해 탐색하는 시선측정이 가능합니다. '자유글 시선측정'은 다음과 같은 문서에 대해 시선측정을 제공합니다.

* PDF 파일 형식만 가능
* 최대 20페이지까지의 PDF문서만 가능
* 결과 보고서의 제공

## 진단 결과는 어떻게 제공되나요?

자유글 시선측정은 학생이 문서를 탐색한 과정을 **있는 그대로 기록해서 보여주는 방식**으로 결과를 제공합니다.

* 학생이 읽는 동안의 시선, 응시, 화면 위치(스크롤)를 모두 기록하여 영상처럼 재생할 수 있습니다.
* 문서 전체에 대한 평균 응시시간과 응시 비율을 보여줍니다.
* 화면에 표시된 시선 기록을 보고서로 다운로드할 수 있습니다.

### 읽기진단(Reading)과 같은 읽기분석 리포트는 제공되지 않습니다

읽기진단의 상세 리포트는 **미리 등록된, 조건이 통제된 지문**이기 때문에 가능합니다. 자유글은 사용자가 올리는 자유로운 형식의 문서이므로, 다음의 이유로 같은 분석이 성립하지 않습니다.

* **단어의 위치를 알 수 없습니다.** 읽기진단의 지문은 각 단어가 화면 어디에 있는지 정해져 있어서 시선을 단어 단위로 분석할 수 있지만, 자유글은 그림·도표가 섞인 자유로운 레이아웃이라 시선이 닿은 곳이 어떤 단어인지 알 수 없습니다.
* **글의 난이도를 알 수 없습니다.** 난이도를 모르면 같은 읽기 속도라도 잘 읽은 것인지 판단할 수 없습니다.
* **이해도를 측정하지 않습니다.** 자유글에는 내용 확인 문제가 없으므로 이해 점수를 낼 수 없습니다.
* **또래 비교 기준이 없습니다.** 학생마다 서로 다른 문서를 읽기 때문에, 백분위나 또래 비교처럼 같은 조건에서 쌓인 데이터가 필요한 지표를 만들 수 없습니다.

{% hint style="info" %}
자유글 시선측정은 점수를 매기는 진단이 아니라, 학생이 문서를 **어떤 방식으로 탐색하는지 눈으로 확인하고 비교하는 도구**입니다. 읽기능력의 점수화된 분석이 필요하다면 읽기진단(Reading)을 이용하세요.
{% endhint %}
