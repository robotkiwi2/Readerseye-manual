# 시선읽기훈련

## 개요

시선읽기훈련은 시선추적 기술을 활용하여 읽기의 기본이 되는 안구운동 패턴을 습득하는 훈련 프로그램입니다. 학생들이 글을 읽을 때 필요한 효율적인 시선 이동 방식을 자연스럽게 습득할 수 있습니다.

## 훈련의 특징

- **기본 읽기 능력 개발**: 문장과 줄을 따라가는 기본적인 안구운동 패턴 학습
- **시선 안정성 향상**: 읽기 중 시선의 안정성과 정확성 강화
- **읽기 속도 개선**: 효율적인 시선 이동을 통한 읽기 속도 향상
- **읽기 유창성 강화**: 지속적인 훈련을 통해 자연스럽고 유창한 읽기 능력 개발

## 훈련 구성

- **문장 추적**: 화면상의 문장을 따라 시선을 이동하며 읽기 능력 강화
- **수평 줄바꿈**: 한 줄에서 다음 줄로 자연스럽게 시선을 이동하는 능력 개발
- **수직 줄바꿈**: 다양한 텍스트 레이아웃에서 효율적인 시선 이동 학습
- **수평 도약 운동**: 문장 내에서의 정확한 시선 이동 능력 강화
