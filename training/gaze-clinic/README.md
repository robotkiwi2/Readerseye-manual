# 시선클리닉

## 개요

개인별 시선 특성을 분석하여 맞춤형 개선 방안을 제시하는 전문 클리닉 서비스입니다.

## 훈련의 목적

시선클리닉은 읽기능력 진단(인지검사)으로 드러난 시선 관련 문제점들을 개선하도록 고안된 훈련입니다. 진단 과정에서 측정되는 주요 지표들의 문제를 해결합니다:

- **시선 도약폭이 좁음**: 한 번에 처리하는 정보 범위가 좁은 경우, 시각폭을 확장하고 시선의 안정성을 향상시킵니다
- **응시 시간이 김**: 정보 처리 속도가 느린 경우, 시선 제어 능력을 강화하여 읽기 속도를 개선합니다
- **시선 이동이 불안정함**: 역행이 많거나 시선 이동이 비효율적인 경우, 의도적이고 통제된 시선 이동 능력을 개발합니다
- **시선 추적 능력 부족**: 부드럽고 정확한 시선 추적을 통해 읽기 과정의 안정성을 향상시킵니다

## 훈련 구성

- **직선 추적 훈련**: 기본적인 시선 이동 안정성 개발
- **곡선 추적 훈련**: 복잡한 경로 추적으로 시선의 유연성 향상
- **반응 통제 훈련**: 자동적 반응 억제 및 의도적 시선 제어
- **수동적 공동 주의 훈련**: 타인의 시선 방향 감지 능력
- **능동적 공동 주의 훈련**: 타인의 시선을 의도적으로 유도하는 능력
