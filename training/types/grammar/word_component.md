# 단어의 성분 구분

## 성분(Sentence Element)란?

**성분**은 문장을 이루는 각 단어나 구(phrase)가 문장 내에서 차지하는 위치와 역할을 의미합니다.

**성분과 기능의 차이:**
- **기능**: 단어가 속한 그룹의 특성 (체언, 용언 등)
- **성분**: 문장 내에서 단어가 차지하는 위치와 역할 (주어, 술어, 목적어 등)

**성분과 품사의 차이:**
- **품사**: 단어 자체의 종류 (명사, 동사 등)
- **성분**: 문장 내에서의 역할 (주어, 술어 등)

**예시로 이해하기:**
- "우리는 학교에서 공부한다"
  - "우리" = 품사: 대명사 / 성분: 주어 / 기능: 체언
  - "한다" = 품사: 동사 / 성분: 술어 / 기능: 용언

**성분을 알아야 하는 이유:**
- 문장의 구조 파악
- 각 단어의 역할과 관계 이해
- 문장의 의미 정확히 파악
- 읽기 이해력 향상

## 개요

단어의 성분 구분은 문장 내에서 단어들이 어떤 성분으로 기능하는지 파악하는 훈련입니다. 문장의 구조를 정확히 이해하면 글의 의미를 명확하게 파악할 수 있습니다.

## 문장의 7가지 성분

### 1. 주어 (主語)
**역할**: 문장에서 동작이나 상태의 주체를 나타냄
**특징**: 보통 문장의 시작에 오며, 조사 '이/가'나 '은/는'과 함께 사용
**예시**: "**나는** 학교에 간다" (나 = 주어)

### 2. 술어 (述語)
**역할**: 주어의 동작이나 상태를 설명
**특징**: 일반적으로 문장의 끝에 오며, 동사나 형용사로 표현
**예시**: "나는 학교에 **간다**" (간다 = 술어)

### 3. 목적어 (目的語)
**역할**: 동사의 행동이 미치는 대상을 나타냄
**특징**: 조사 '을/를'과 함께 사용
**예시**: "나는 **책을** 읽는다" (책 = 목적어)

### 4. 보어 (補語)
**역할**: 주어나 목적어의 상태나 성질을 보충 설명
**특징**: 조사 '이/가' 또는 '으로/로'와 함께 사용
**예시**: "그는 **의사가** 된다" (의사 = 보어)

### 5. 관형어 (冠形語)
**역할**: 명사를 수식하여 그 의미를 한정
**특징**: 명사 바로 앞에 위치
**예시**: "**새로운** 책을 샀다" (새로운 = 관형어)

### 6. 부사어 (副詞語)
**역할**: 동사나 형용사의 의미를 수식
**특징**: 문장 내 여러 위치에 올 수 있음
**예시**: "**빨리** 달렸다" (빨리 = 부사어)

### 7. 독립어 (獨立語)
**역할**: 다른 문장 성분과 직접적인 문법적 관계가 없음
**특징**: 감탄사나 부름말로 사용
**예시**: "**아**, 이거 정말 좋구나!" (아 = 독립어)

## 훈련 방법

주어진 문장의 각 단어를 선택한 후 해당 성분에 맞도록 하단의 버튼을 눌러서 할당합니다.

**단계별 진행:**
1. 화면에 제시된 문장을 읽음
2. 각 단어를 클릭하여 선택
3. 단어의 성분(주어, 술어, 목적어, 보어, 관형어, 부사어, 독립어)을 판단
4. 해당하는 버튼을 눌러 성분 할당
5. 모든 단어 할당 완료 시 정답 확인
