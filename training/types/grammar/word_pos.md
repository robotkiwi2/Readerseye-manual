# 단어의 품사 구분

## 품사(Part of Speech)란?

**품사**는 단어를 문법적 특징에 따라 분류한 것입니다. 같은 종류의 품사는 문법적 성질이 비슷하고, 문장에서 사용되는 방식이 유사합니다.

**품사와 기능의 차이:**
- **품사**: 단어 자체의 분류 (9가지: 명사, 동사, 형용사 등)
- **기능**: 여러 품사가 모여 이루는 역할 그룹 (5가지: 체언, 용언 등)

**품사와 성분의 차이:**
- **품사**: 단어 자체의 종류 (변하지 않음)
- **성분**: 문장 내에서 단어가 하는 역할 (주어, 술어, 목적어 등)

**품사를 알아야 하는 이유:**
- 올바른 문법 규칙 적용
- 단어의 쓰임새 이해
- 문장 구조 파악
- 읽기 이해력 향상

## 개요

단어의 품사 구분은 한국어의 9가지 기본 품사를 구분하는 훈련입니다. 각 단어의 정확한 품사를 파악하면 문법 규칙을 이해하고 글의 의미를 더 정확히 파악할 수 있습니다.

## 9가지 품사

### 1. 명사 (名詞)
**의미**: 사물, 동물, 개념 등을 나타내는 단어
**특징**: 문장의 주어나 목적어가 됨
**예시**: 책, 학생, 사랑, 아침

### 2. 대명사 (代名詞)
**의미**: 명사를 대신하여 나타내는 단어
**특징**: 명사처럼 작용하지만 반복을 피함
**예시**: 나, 그, 우리, 이것

### 3. 수사 (數詞)
**의미**: 수량이나 순서를 나타내는 단어
**특징**: 명사 앞에 붙어 개수나 순서를 표현
**예시**: 하나, 둘, 셋, 첫째

### 4. 조사 (助詞)
**의미**: 명사나 대명사 뒤에 붙어 문법적 관계를 나타냄
**특징**: 독립적으로 사용되지 않으며 조사만으로 의미 전달 불가
**예시**: 이, 을, 에, 와, 으로

### 5. 관형사 (冠形詞)
**의미**: 명사 앞에 붙어 명사를 수식하는 단어
**특징**: 명사와 조합하여 의미 완성
**예시**: 새로운, 큰, 작은, 아름다운

### 6. 부사 (副詞)
**의미**: 동사나 형용사, 다른 부사를 수식하는 단어
**특징**: 문장의 상황이나 방식, 정도를 나타냄
**예시**: 빨리, 천천히, 매우, 아주

### 7. 동사 (動詞)
**의미**: 동작이나 행동을 나타내는 단어
**특징**: 시제 변화가 있고 문장의 서술어가 됨
**예시**: 먹다, 자다, 가다, 읽다

### 8. 형용사 (形容詞)
**의미**: 사물의 성질이나 상태를 나타내는 단어
**특징**: 명사를 꾸미거나 서술어로 사용
**예시**: 크다, 작다, 아름답다, 우아하다

### 9. 감탄사 (感嘆詞)
**의미**: 감정이나 의사를 나타내는 단어
**특징**: 독립적으로 사용되며 다른 말과 문법적 관계가 없음
**예시**: 아, 오, 어라, 헉, 와

## 훈련의 효과

- 한국어 기본 문법 체계 이해
- 단어별 정확한 역할 파악
- 읽기 중 품사 인식을 통한 이해력 향상
