# 훈련(트레이닝) 종류

웹 트레이닝은 Reading (읽기  트레이닝)과 cognitive (인지 트레이닝)으로 구성되며, 학생이 집에서 PC나 타블렛을 이용하여 수행할 수 있습니다.

## 읽기 훈련 Reading Training

* 차례차례읽기 Sentence Mask
* 키워드 찾기 Keyword Finding
* 카테고리 찾기 Category Finding
* 글 읽기 Textbook
* 순서맞추기 word Ordering
* 빠르게 읽기 RSVP
* 의미덩이 끊어읽기 Chunking

## 인지 훈련 Cognitive Training

* 한눈에 읽기 Visual Span
* 한눈에 세기 Visual Counting
* 순서 잇기 TMT
* 스트룹 테스트 Stroop Test

## 문법  훈련Grammar   Training

* 단어기능 구분 Roel of Word
* 단어품사 구분 Part of Speech
* 문장성분 구분 Part of Structure
