# 웹훈련

웹훈련은 언어영역훈련, 인지영역훈련, 문법영역훈련으로 구성되며, 학생이 집에서 PC나 태블릿을 이용하여 수행할 수 있습니다. 읽기 속도와 이해력 향상, 인지 능력 발달, 문법 이해력 증진 등 다양한 목표를 통합적으로 달성할 수 있도록 설계되었습니다.

## 언어영역훈련

* 차례차례읽기 Sentence Mask
* 키워드 찾기 Keyword Finding
* 카테고리 찾기 Category Finding
* 글 읽기 Textbook
* 순서맞추기 word Ordering
* 빠르게 읽기 RSVP
* 의미덩이 끊어읽기 Chunking

## 인지영역훈련

* 한눈에 읽기 Visual Span
* 한눈에 세기 Visual Counting
* 순서 잇기 TMT
* 스트룹 테스트 Stroop Test

## 문법영역훈련

* 단어기능 구분 Roel of Word
* 단어품사 구분 Part of Speech
* 문장성분 구분 Part of Structure
