# 웹훈련

웹훈련은 언어영역훈련, 인지영역훈련, 문법영역훈련으로 구성되며, 학생이 집에서 PC나 태블릿을 이용하여 수행할 수 있습니다. 읽기 속도와 이해력 향상, 인지 능력 발달, 문법 이해력 증진 등 다양한 목표를 통합적으로 달성할 수 있도록 설계되었습니다.

## 언어영역훈련

* 차례차례읽기 Sentence Mask
* 키워드 찾기 Keyword Finding
* 카테고리 찾기 Category Finding
* 글 읽기 Textbook
* 순서맞추기 word Ordering
* 빠르게 읽기 RSVP
* 의미덩이 끊어읽기 Chunking

## 인지영역훈련

* 한눈에 읽기 Visual Span
* 한눈에 세기 Visual Counting
* 순서 잇기 TMT
* 스트룹 테스트 Stroop Test

## 문법영역훈련

* 단어기능 구분 Roel of Word
* 단어품사 구분 Part of Speech
* 문장성분 구분 Part of Structure

## 웹훈련 프로그램 구성

| 영역 | 훈련명 | 내용 | 훈련 효과 |
|------|--------|------|----------|
| **언어영역훈련** | 차례차례 읽기 | 일정한 속도로 한 문장씩 제시되는 글 읽기 | 읽기 속도 향상, 시선 분산 방지 |
| | 키워드 찾기 | 글에서 주어진 핵심 단어 찾아내기 | 정보 탐색 능력, 읽기 속도 개선 |
| | 카테고리 찾기 | 글의 카테고리, 주제, 또는 중심 내용 파악하기 | 읽기 이해력, 종합적 사고 향상 |
| | 글 읽기 | 다양한 주제의 실제 글을 읽고 이해도 점검 | 실제 읽기 능력, 종합 이해력 향상 |
| | 순서 맞추기 | 섞인 문장을 올바른 순서대로 배열하기 | 논리적 사고, 문장 이해 능력 강화 |
| | 빠르게 읽기 (RSVP) | 빠른 속도로 제시되는 단어 읽기 | 읽기 속도 향상, 즉각적 단어 인식 |
| | 의미덩이 끊어읽기 | 의미 있는 단위로 글을 나누어 읽기 | 읽기 이해력 향상, 읽기 속도 개선 |
| **인지영역훈련** | 한눈에 세기 | 순간 제시된 점의 개수 빠르게 파악하기 | 시각폭 확장, 기초 인지능력 발달 |
| | 한눈에 읽기 | 순간 제시된 글자 한 눈에 인식하고 기억하기 | 시각폭 확장, 읽기 속도 40-60% 개선 |
| | 순서 잇기 | 순서대로 숫자와 문자를 연결하기 | 주의집중력, 인지 유연성 강화 |
| | 스트룹 테스트 | 색 이름과 실제 색이 다를 때 반응하기 | 충동 통제, 선택적 주의집중력 개선 |
| **문법영역훈련** | 단어의 기능 구분 | 문장에서 각 단어의 기능(체언, 용언 등) 파악 | 문법적 구조 이해, 읽기 이해력 향상 |
| | 단어의 품사 구분 | 문장의 단어를 품사별로 정확히 분류하기 | 기본 문법 체계 이해, 언어 능력 강화 |
| | 단어의 성분 구분 | 문장 성분(주어, 술어, 목적어 등) 파악하기 | 문장 구조 이해, 읽기 이해력 강화 |
