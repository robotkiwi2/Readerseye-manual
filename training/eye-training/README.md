# 눈 훈련

눈 훈련은 시선추적 기술을 활용하여 안구운동 능력과 시선 통제력을 향상시키는 전문 훈련 프로그램입니다. 읽기 및 학습능력의 기반이 되는 시지각 능력, 시선통제, 주의집중력을 향상시킵니다. 게임 형태로 제작되어 학생들이 거부감 없이 훈련에 참여할 수 있으며, 시선추적 장비가 설치된 컴퓨터에서 수행합니다.

## 시선게임

* 도약안구운동 게임
* 추적안구운동 게임
* 선택적 시선통제 게임

## 시선읽기훈련

* 문장 추적
* 수평 줄바꿈
* 수직 줄바꿈
* 수평 도약 운동

## 시선클리닉

* 직선 추적 훈련
* 곡선 추적 훈련
* 반응 통제 훈련
* 수동적 공동 주의
* 능동적 공동 주의

## 눈 훈련 프로그램 구성

| 범주 | 훈련명 | 내용 | 훈련 효과 |
|------|--------|------|----------|
| **시선게임** | 도약안구운동 게임 | 특정 위치의 자극에 빠르게 반응하여 시선 이동 | 도약안구이동 능력, 응시유지력 향상 |
| | 추적안구운동 게임 | 움직이는 목표물을 부드럽게 따라가기 | 추적안구운동 능력, 시선통제력 향상 |
| | 선택적 시선통제 게임 | 자극의 반대 방향으로 시선 이동하기 | 도약안구운동, 시각반응통제, 집중력 향상 |
| **시선읽기훈련** | 문장 추적 | 화면의 문장을 따라 시선으로 읽기 | 읽기 기초 능력, 시선 안정성 강화 |
| | 수평 줄바꿈 | 한 줄에서 다음 줄로 효율적으로 시선 이동 | 효율적인 줄바꿈, 읽기 속도 개선 |
| | 수직 줄바꿈 | 다양한 레이아웃에서 시선 이동 | 레이아웃 적응력, 읽기 유연성 향상 |
| | 수평 도약 운동 | 문장 내에서 정확하고 빠른 시선 이동 | 시선 정확성, 읽기 효율성 강화 |
| **시선클리닉** | 직선 추적 훈련 | 일정한 경로를 따라 시선 이동 | 안정적인 시선 이동, 시선 정확성 향상 |
| | 곡선 추적 훈련 | 복잡한 곡선 경로를 따라 시선 이동 | 시선의 유연성, 고급 시선통제 능력 |
| | 반응 통제 훈련 | 자동적 반응을 억제하고 의도적으로 시선 제어 | 충동 통제, 의도적 시선 이동 능력 |
| | 수동적 공동 주의 | 타인의 시선 방향을 감지하고 따라가기 | 타인의 시선 감지, 사회적 상호작용 능력 |
| | 능동적 공동 주의 | 자신의 관심사로 타인의 시선 유도하기 | 시선 유도 능력, 효과적인 의사소통 |
