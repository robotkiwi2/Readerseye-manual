# 등록 모드 설정

미리 등록된 학생들을 대상으로만 진단하는 등록모드의 설정입니다.

## 등록모드 기본 설정

### 제목 설정하기

진단사이트의 준비 화면에 표시될 제목입니다.

<figure><img src="../../.gitbook/assets/image (9).png" alt=""><figcaption></figcaption></figure>

제목을  이용하여 진단의   결과를 구분할 수 있기 때문에,  진단 이벤트에 따라 명확하게 제목을 작성해 주십시오.&#x20;

'2023년 1학기 1학년 읽기측정' 같은 방식이 권장됩니다.

### 등록사용자 설정

<figure><img src="../../.gitbook/assets/image (8).png" alt=""><figcaption></figcaption></figure>

* 등록사용자 선택방식 : 사용자를 어떻게 선택할지를 결정합니다.
* 사용허용 그룹 :  체크되어 있는 그룹만 사용할 수 있습니다.

## 읽기능력 진단

<figure><img src="../../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>

#### 진단 언어&#x20;

&#x20;어떤 언어로 진단할지 선택합니다. 현재 구독  중인 상품에 따라 선택할 수 있는 언어가 표시됩니다. 최소한 1개 언어는 선택되어 있어야 하며, 복수 선택시 학생이 선택할 수 있습니다

#### 연습 시행

진단을 할 때, 연습시행을 먼저 시킬지를 설정합니다. \[필수]는 반드시 해야 하며, \[선택]의 경우 학생이 체크를 통해 선택할 수 있습니다.

{% hint style="warning" %}
\[익명모드]로 할 경우엔 가급적 연습시행을\[필수]로 설정하십시오.
{% endhint %}

#### 결과 제공

진단 완료 후 결과를 어떻게 볼 수 있는지 설정합니다.

#### 재수행 금지시간

학생이 반복적으로 진단을 재수행하는 것을 막기 위해서, 일정 시간이 지나야만 재수행 할 수 있도록 설정할 수 있습니다.

#### 진단글 설정

어떤 글로 진단할 지 설정합니다.

* 연령대별 지정 : 나이대 별로, 진단글을 미리 설정합니다.
* 연령 자동 추천 : 학생의 나이에 따라, 자동으로 진단글을 추천해 줍니다.
* 연령글 자유선택 : 학생의 나이에 맞는 글 중에서 직접 선택합니다.
* 자유 선택 : 모든 글 중에서 자유롭게 선택합니다.
* 그룹별 지정 : 학생이 속한 그룹별로, 진단글을 미리 설정합니다.

{% hint style="info" %}
## 글을 지정하는 방법에 대해서는 다음 섹션인 \[익명모드 설정]에서 설명합니다.
{% endhint %}

#### 진단글 범위

자동 추천 또는 자유 선택시, 어떤 풀을 대상으로 할지 설정합니다.
