# 익명 모드 설정

## 익명모드 기본 설정

* 익명모드제목    : 키오스크 단말기에 보여지는 제목을 설정합니다. 제목을  이용하여 진단의   결과를 구분할 수 있기 때문에,  진단 이벤트에 따라 명확하게 제목을 작성해 주십시오. '2023년 1학기 1학년 읽기측정' 같은 방식이 권장됩니다.

### 진단글 범위

* 연령대별 지정 : 학생의 연령대에 따라, 관리자가 설정해 놓은 지정 글로 진단하게 됩니다.
* 연령 자동 추천 : 학생의 연령에 따라, 자동으로 추천된 글로 진단하게 됩니다.
* 연령글 자유선택 : 학생의 연령에 맞게 제시된 여러 진단글 중에서 학생이 선택할 수 있습니다.
* 자유선택 : 학생이 진단글을 자유롭게 선택합니다.

{% hint style="info" %}
\[연령대별 지정]에서, 학생의 나이와 가장 가까운 지정 연령의 글이 제시됩니다.

즉,  관리자가 7세와 10세를 설정해 두었다면, 8.2세인 학생은 7세 지정글이 제시됩니다.
{% endhint %}

{% hint style="info" %}
연령대별 지정, 연령 자동추천, 그룹별 지정의 경우, 학생이 반복 진단하더라도 같은 글만 제시됩니다.
{% endhint %}

### 진단글 지정

연령대별 지정, 그룹별 지정의 경우, 다음 화면에서 각 대상에 대한 글을 직접 선택하십시오.

<figure><img src="../../.gitbook/assets/image (465).png" alt=""><figcaption></figcaption></figure>

체크박스로 선택된 그룹만 진단이 가능합니다. (선택한 그룹 목록만  키오스크에서 보여집니다. )

\[선택수정]버튼을 눌러서, 그룹별로 진단글을 설정할 수 있습니다.

<figure><img src="../../.gitbook/assets/image (419).png" alt=""><figcaption></figcaption></figure>

\[변경]버튼을 눌러 진단글을 변경할 수 있습니다.

#### 연령별 지정(등록모드/익명모드 공통)

학생의 나이에 따라 진단글을 정할 수 있습니다.

<figure><img src="../../.gitbook/assets/image (435).png" alt=""><figcaption></figcaption></figure>

모든 나이별로 설정해야 하는 것이 아니며, 몇  개의 연령만 설정해 두면, 학생의 만나이와 가장 가까운 \[설정연령]의 글이 제시됩니다.

{% hint style="info" %}
기본값으로 7,8,11,13,15,17,19세 연령에 대한 진단글이 설정되어 있습니다. 연령을 삭제하거나 추가하거나 변경할 수 있습니다.
{% endhint %}
