# 진단사이트(키오스크) 설정

## 진단사이트  설정 탭으로 이동

좌측 조직도에서 \[기관]을 선택하고, 우측 탭에서 \[진단사이트 설정]탭을 선택하세요.

<figure><img src="../../.gitbook/assets/image (676).png" alt=""><figcaption></figcaption></figure>

진단사이트는 등록 모드, 익명 모드, 교사 모드의 세 가지 모드에 대한 설정이 가능합니다. 모드 별로 설정해 두더라도, 실제 진단 사이트에서 어떤 모드를 사용할지는 진단사이트의 설정 페이지(kiosk.eyestudent.com)에서 정할 수 있습니다.

등록/진단 모드 별로 다르게 설정할 수 있습니다.

<figure><img src="../../.gitbook/assets/image (677).png" alt=""><figcaption></figcaption></figure>
