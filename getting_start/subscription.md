# 구독하기

## 결제수단  추가하기

\[기관노드]를 선택하고  \[구독 및 결제]탭을 선택하십시오.

<figure><img src="../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>

하단의 \[결제 수단] 영역에 내려가서 \[결제 수 추가] 버튼을 누르고 결제용 신용카드를 추가하십시오.

<figure><img src="../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure>

신용카드정보를 입력하고 진행하여 결제수단을 등록합니다.

<figure><img src="../.gitbook/assets/image (30).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
향후 다른 카드를 등록하거나, 결제용 카드를 변경할 수 있습니다. 이 때 등록한 카드의 \[활성화]버튼을 누르면 됩니다.
{% endhint %}

{% hint style="info" %}
카드 등록, 구매하는 컴퓨터와 장비를 설치하는 컴퓨터가 같을 필요는 없습니다.

스마트폰으로 접속해서 결제 수단을 등록하고 구독을 진행해도 됩니다.
{% endhint %}

## 구독하기&#x20;

가입을 했어도, 구독을 해야 리더스아이 서비스를 활용할 수 있습니다.&#x20;

\[기관노드]를 선택하고  \[구독관리]탭을 선택하십시오.

<figure><img src="../.gitbook/assets/image (299).png" alt=""><figcaption></figcaption></figure>

구독버튼을 눌러 구독할 수 있으며 구독료는 월 단위로 과금됩니다. 과금일은 무료 사용 기간 후  첫 출금이 일어난 날짜입니다.  &#x20;

{% hint style="info" %}
부가세(v.a.t)가 포함된 가격이며, 상품 및 가격 정책은 변동될 수 있으므로 해당 메뉴에서 최종 확인하시기 바랍니다.
{% endhint %}

### 진단 장비 임대

구독기간 동안 시선추적 장비를 임대해 드립니다. 진단 장비는 리더스아이의 자산이며, 구독이 종료되면 반납해야 합니다.

장비의 분실하거나 파손할 경우 사용자가 배상해야 합니다.&#x20;

### 솔루션 구매&#x20;

월 구독이 아닌 연간 구독, 영구 라이센스 구매 등은 별도로 문의하시기 바랍니다.
