# 자유글 탭

## 자유글이란?

관리자가 원하는 문서를 등록하여 시선이동을 측정할 수 있습니다.&#x20;

pdf 파일만 가능하며, 시선측정 보고서가 제공됩니다.

### 자유글 측정 현황

등록된 자유글별로, 기관의 학생들의 측정 수행율을 표시합니다.\
카드를 클릭하면 해당 자유글을 미리보기 할 수 있습니다.

<figure><img src="../../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>

### 자유글 측정 결과

개별 자유글 측정 결과 목록입니다. 원하는 행을 클릭하면 결과 보고서를 볼 수 있습니다.

<figure><img src="../../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>

{% hint style="danger" %}
자유글을 삭제하면 그 글에 대한 측정 결과는 볼 수 없습니다.
{% endhint %}

## 자유글 관리하기

자유글을 등록하거나 수정, 삭제합니다. 이 박스는 관리자에게만 보입니다.

### 자유글 목록

현재 등록되어 있는 자유글의 목록입니다. 버튼으로 자유글을 생성, 수정, 삭제할 수 있습니다.

<figure><img src="../../.gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure>

### 자유글 추가하기 (수정하기)

새로운 자유글(pdf파일)을 등록합니다. 최대 20페이지 분량의 문서를 등록할 수 있습니다.

{% hint style="info" %}
등록할 수 있는 자유글의 갯수는 구독에 따라 다릅니다.
{% endhint %}

<figure><img src="../../.gitbook/assets/image (14).png" alt=""><figcaption></figcaption></figure>

#### 읽기 시간 제한

자유글로 시선 측정을 수행할 최대 시간을 지정합니다. 최대 20분까지 지정할 수 있습니다.

#### 펜 도구 설정

학생이 자유글을 보면서 마우스를 드래그하여 펜처럼 쓸 수 있는 기능을 허용합니다.\
펜의 굵기와 색상을 설정할 수 있습니다.

### 배율 조정하기 (미리보기)

학생이 측정할 때 보여지는 자유글 문서의 크기(배율)을 조정합니다. 미리보기 창을 열어서 배율을 확인하며 설정할 수 있습니다.
