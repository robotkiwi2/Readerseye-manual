# 소통

## 시스템  공지사항

리더스아이 서비스의 기술적(시스템) 공지를 제시합니다.

업데이트, 사용제한 안내, 버그패치 등에 대한 안내가 제시되며, 중요한 공지는 로그인 시 팝업으로 제공됩니다.

<figure><img src="../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

## 조직 공지사항

소속된 조직(org)에서 공지한 공지사항이 표시됩니다.

## 질문과 답변

리더스아이에 질문을 할 수 있습니다. 운영사에서 답변을 달 수 있습니다.

## 학생 질문과 답변

기관에 속한 학생이 학생사이트에서 작성한 질문이 보여집니다. 관리자나 선생님은 각 질문에 답변을 달 수 있습니다.
