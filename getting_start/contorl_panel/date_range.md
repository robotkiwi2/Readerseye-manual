# 조회기간 설정

조회기간은 리더스아이의 모든 자료를 조회하는 기준 기간입니다. 제어 패널 상단의 조회기간 바에서 설정하며, 여기서 설정한 기간이 읽기진단, 훈련, 인지검사, 자유글 등 모든 탭의 자료와 조직도의 요약 정보에 공통으로 적용됩니다.

<!-- 스크린샷 추가 위치: 제어 패널 상단의 조회기간 바 -->

조회기간 바에는 현재 설정된 기간이 `시작일 ~ 종료일` 형태로 표시됩니다.

{% hint style="info" %}
처음 사용할 때에는 조회기간이 **최근 6개월**로 설정되어 있습니다. 한 번 변경한 조회기간은 브라우저에 저장되어, 다음에 접속할 때에도 그대로 유지됩니다.
{% endhint %}

## 최근 기간에서 선택하기

조회기간 바 우측의 선택 상자에서 자주 쓰는 기간을 바로 선택할 수 있습니다.

* 오늘
* 어제부터
* 최근 1주일
* 최근 1개월
* 최근 3개월
* 최근 6개월
* 최근 1년

선택하면 오늘을 종료일로 하여 조회기간이 즉시 변경됩니다. 달력으로 기간을 직접 지정한 경우에는 선택 상자에 '직접 설정'이라고 표시됩니다.

## 달력으로 직접 설정하기

표시된 기간 또는 달력 아이콘을 클릭하면 두 개의 달력이 열립니다. 왼쪽 달력에서 시작일을, 오른쪽 달력에서 종료일을 선택하고 \[확인] 버튼을 누르면 적용됩니다.

<!-- 스크린샷 추가 위치: 시작일/종료일 달력 -->

{% hint style="warning" %}
날짜를 직접 설정할 때에는 다음의 제한이 있습니다.

* 미래의 날짜는 선택할 수 없습니다.
* 종료일은 시작일보다 이전일 수 없습니다.
* 조회기간은 최대 1년까지 설정할 수 있습니다.
{% endhint %}

## 단위별 기간 선택

달력 아래의 \[단위별 기간 선택] 버튼을 누르면, 학기나 회계 단위처럼 정해진 기간을 간편하게 선택할 수 있습니다.

<!-- 스크린샷 추가 위치: 단위별 기간 선택 모달 -->

1. **연도**를 선택합니다.
2. **단위**를 연도별, 반기별, 분기별, 월별 중에서 선택합니다.
3. 반기별, 분기별, 월별을 선택했다면 **시기**(상반기/하반기, 1\~4분기, 1\~12월)를 선택합니다.
4. \[적용] 버튼을 누르면 해당 기간이 조회기간으로 설정됩니다.

{% hint style="info" %}
올해를 선택한 경우, 아직 시작되지 않은 시기는 목록에 나타나지 않으며, 현재 진행 중인 시기를 선택하면 오늘까지가 조회기간이 됩니다.
{% endhint %}

## 조회기간이 적용되는 곳

조회기간을 변경하면 다음의 자료들이 모두 새 기간을 기준으로 다시 표시됩니다.

* 조직도의 학생 노드에 표시되는 R/T/S 요약 아이콘과 막대그래프 차트
* \[읽기진단], \[훈련], \[인지검사], \[자유글] 탭의 조회 결과와 그래프
* 조회기간을 전반기와 후반기로 나누어 보여주는 전후 비교(증감 표시)
* 조회기간 동안의 변화를 분석하는 종합 결과보고서

{% hint style="info" %}
학생의 진단·훈련 기록이 보이지 않는다면, 기록이 없는 것이 아니라 조회기간 밖에 있을 수 있습니다. 먼저 조회기간을 넓혀서 다시 확인해 보세요.
{% endhint %}
