# 제어 패널과 조직도

조직도는 나의 기관에 속한 모든 구성원들을 체계적으로 관리하며 한 눈에 상태를 파악할 수 있습니다.

<figure><img src="../../.gitbook/assets/image (39).png" alt=""><figcaption></figcaption></figure>

노드(node)

조직도에서 그룹이나학생을표시하는가로막대를 노드(node)라고 부릅니다. 각 노드는 선택하고, 마우스로 위치를 옮기거나, 우클릭하여 메뉴를 사용할 수 있습니다.

어떤 노드를 선택하느냐에 따라 우측의 탭    영역의 내용이 다르게 나타납니다.

* 그룹 노드 : 그룹 노드는 접히거나 펼쳐질 수 있으며, 구성원 노드들이 그룹에 속합니다.
* 학생노드 : 학생노드는 하나의그룹에 속하며, 학생 개인 및 선생님 개인을 의미합니다.

### 기관 노드

기관(agency)노드는 나의 기관(학원, 학교 등) 전체를 의미합니다.

<figure><img src="../../.gitbook/assets/image (40).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
기관 노드는 관리자(agency)로 로그인했을 때에만 보여집니다. 선생님이나 학생에게는 보이지 않습니다.
{% endhint %}

### 선생님 그룹

선생님 그룹 노드는 선생님들이 속하는 그룹입니다.

<figure><img src="../../.gitbook/assets/image (691).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
선생님 그룹노드는 관리자(agency)로 로그인했을 때에만 보여집니다. 선생님이나 학생에게는 보이지 않습니다.
{% endhint %}

### 그룹 노드

원하는 그룹을 만들 수 있습니다. 그룹 노드에 속한 학생(user)들이 구성원 노드로 속하게 됩니다.

<figure><img src="../../.gitbook/assets/image (690).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
선생님은 자신에게 권한이 할당된 그룹  노드만 볼 수 있습니다.
{% endhint %}

### 기본 그룹 노드

기본 그룹 노드는 특정 그룹에 할당되지 않은 모든 학생들이 자동으로 속하게 됩니다.

<figure><img src="../../.gitbook/assets/image (689).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
관 노드, 선생님 노드, 기본그 룹 노드는 삭제하거나 이름을 바꿀 수 없습니다.
{% endhint %}

### 학생 노드

학생(구성원) 노드에는 학생의 닉네임, ID, 나이 정보와 3가지 진단결과에 대한 요약정보가 아이콘으로 표시됩니다.

<figure><img src="../../.gitbook/assets/image (692).png" alt=""><figcaption></figcaption></figure>

* R : 시선 읽기진단 수행 현황
* T : Web 트레이닝 수행 현황
* S : 안구운동 검사 수행 현황

각 아이콘의 색상은 다음을 의미합니다.

* 회색 : 최근에 수행한 내역이 없음
* 초록색 ; 최근 수행 결과가 문제 없음
* 주황색 : 최근 수행 결과가 미흡함
* 빨간색 : 최근 수행 결과가 주의를 요함

각 아이콘을 클릭하면, 관계된 탭으로 이동합니다.

### 선생님 구성원 노드

선생님 노드에는 닉네임과  아이디가 표시됩니다.

<figure><img src="../../.gitbook/assets/image (720).png" alt=""><figcaption></figcaption></figure>

선생님에게는 다음의 두가지 권한을 설정할 수 있습니다.&#x20;

* 학생 권한 아이콘 : 학생을 추가, 수정, 삭제, 이동할 수 있습니다.
* 그룹 권한 아이콘 : 특정 그룹에 대한 조회 권한이 있습니다.

## 트리 조작하기

### 구성원 검색 및 정렬 버튼

학생들이 많을 경우, 구성원 노드를 순차적으로 정렬해야 할 때가 있습니다. 이 때, 정렬방식을 선택하면 정렬되며, 상/하 화살표 버튼으로 오름차순, 또는 내림차순으로 순서를 바꿀 수 있습니다.

기본값은 이름 오름차순(가나다..)로 되어 있습니다.

#### 학생 정렬하기

학생들을 이름순, 아이디순, 생년월 순으로 정렬할 수 있습니다.

우측 상하버튼을 이용하여 오름차순, 내림차순을 선택합니다.

<figure><img src="../../.gitbook/assets/image (712).png" alt=""><figcaption></figcaption></figure>

#### 나이 표시하기

학생의 나이를 나이, 생년월, 학년으로 표시할 수 있습니다.\
학년은 나이를 기반으로 자동 설정되지만, 개별적으로 수정할 수도 있습니다.

<figure><img src="../../.gitbook/assets/image (713).png" alt=""><figcaption></figcaption></figure>

#### 재학생만 보기

슬라이더를 이용해서 조직도에 '등록된 재학생만' 보거나, '익명 학생과 휴학생을 포함'한 전체 목록을 볼 수 있습니다.

### 노드의 편집과 이동

#### 추가 버튼으로 생성하기

트리영역 상단의 버튼을 이용하여 노드를 추가할 수 있습니다.

<figure><img src="../../.gitbook/assets/image (711).png" alt=""><figcaption></figcaption></figure>

#### 우클릭 메뉴를 사용하기

노드에서 우클릭하면 나타나는 메뉴를 이용하여 수정하거나 추가할 수 있습니다.

<figure><img src="../../.gitbook/assets/image (710).png" alt=""><figcaption></figcaption></figure>

#### \[정보]탭에서 변경하기

노드를 선택하고, 우측 \[정보]탭에서 삭제 또는 수정할 수 있습니다. 이 내용은 정보탭 챕터에서 설명합니다.

<figure><img src="../../.gitbook/assets/image (709).png" alt=""><figcaption></figcaption></figure>

#### 마우스로 노드의 위치를 옮기기

그룹노드를 마우스로 드래그하여 위치를 옮길 수 있습니다.

<figure><img src="../../.gitbook/assets/image (708).png" alt=""><figcaption></figcaption></figure>

학생 구성원 노드를 마우스로 드래그하여 다른 그룹으로 이동시킬 수 있습니다.

<figure><img src="../../.gitbook/assets/image (707).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
그룹 내에서 학생 구성원 노드의 위치를 변경할 수 없습니다. 학생 구성원 노드는 정렬방식에 따라 순서가 계속 바뀔 수 있습니다.
{% endhint %}
