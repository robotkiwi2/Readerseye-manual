# 트레이닝 관리하기(ver.1)

교사가 학생의 트레이닝을 할당하고 수행내역을 관리하는 기능입니다.  .

## 트레이닝 과제 주기

트레이닝 메뉴에서 학생을 선택하면 하단에 Task 목록이 나타납니다. <새 트레이닝 생성>을 클릭하여 새 Task를 만들 수 있습니다. 학생은 할당된 Task외에는 수행할 수 없습니다.

![](<../../.gitbook/assets/image (55).png>)

### 트레이닝 과제 설정하기&#x20;

* 트레이닝 종류를 선택하십시오.
* 트레이닝 레벨을 선택하십시오.
* 하루에 수행해야 하는 반복 횟수를 선택하십시오.

![](<../../.gitbook/assets/image (69).png>)

### 추천 트레이닝 하기  <a href="#recomendation" id="recomendation"></a>

최근 진단 결과와 트레이닝 수행결과를 이용하여, 자동으로 적절한 트레이닝 과제를 생성하는 기능입니다.&#x20;

* 최근 진단에서 상대적으로 부진한 분야에 필요한 트레이닝을 순차적으로 추천합니다.
* 최근 해당 트레이닝의 점수가 평균 80점 이상이면 높은 트레이닝 레벨을 추천합니다.
* 최근 해당 트레이닝의 점수가 평균 40점 이하이면 은 트레이닝 레벨을 추천합니다.
* 점수가 없는 트레이닝의 경우, 난이도 응답에 따라 레벨을 추천합니다.
* 최초 트레이닝일 경우, 5레벨로 1주일간 생성됩니다.

추천 트레이닝 버튼을 누르면 트레이닝 종류와 레벨, 횟수가  정해지며 날짜는 2주일 간으로 생성됩니다. 실제 학생의 수준과 맞지 않을 수 있으 별도로 확인하시기 바랍니다.

### 트레이닝 기간 설정하기

* 시작일과 종료일을 선택하십시오. 달력상에서 날짜를 선택하면 자동으로 기간이 입력됩니다. 디폴트는 2주로 설정되어 있습니다.
* 요일을 선택하십시오. 디폴트는 월요일부터 금요일까지만 선택되어 있습니다.'

### 미리보기 확인

미리보기를 누르면, 해당 레벨의 트레이닝을 수행해 볼 수 있습니다.

{% hint style="info" %}
트레이닝은 지속적으로 업데이트될 예정입니다.
{% endhint %}

## 트레이닝 수행 내역 확인하기

### 일자별 트레이닝 수행 내역 보기

일자별 수행량을 시간으로 볼 수 있습니다. 각 점에 마우스를 올리면 상세 내역이 나타납니다.

![](<../../.gitbook/assets/image (122).png>)

### 과제별 수행 내역 보기

* 각 Task 카드에서, 오늘 수행한 횟수와 할당량을 볼 수 있습니다.
* 각 Task 카드에서, 기간 중 전체 수행량 중 현재까지 수행량을 확인할 수 있습니다.
* 진행 중인 Task는 초록색 진행중 배지가, 기간이 지난 Task는 회색 배지가 표시됩니다.

![](<../../.gitbook/assets/image (187).png>)
