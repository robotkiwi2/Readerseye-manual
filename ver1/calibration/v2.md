# 시선 보정하기 v2

시선 보정은 정확한 시선측정을 위한 과정으로, 사람마다 다르기 때문에 측정하는 사람이 바뀔 때마다 수행해야 합니다.

<figure><img src="../../.gitbook/assets/image (589).png" alt=""><figcaption></figcaption></figure>

## 얼굴의 위치와 거리 맞추기

\[시선보정]을 누르면 다음과 같은 화면이 제시되며, 사람 상체 모양이 나타납니다. 시선추적장치가 사람을 인식하면 그 위치와 거리가 나타납니다. 인식이 잘 되면 \[시선보장 시작] 버튼을 누릅니다.

{% hint style="info" %}
얼굴과 모니터의 거리는 약 60cm 정도가 적당합니다.
{% endhint %}

{% hint style="info" %}
모니터가 얼굴의 정면 높이에 있는 것이 잘 인식됩니다. 노트북과 같이 낮은 위치에서 진단할 경우, 독서대 등을 이용하여 높이를 높이면 인식이 잘 될 수 있습니다.
{% endhint %}

## 시선 보정 시작하기

\[시선보정시작]버튼을 누르면, 아래와 같은 회색 화면에 숫자가 적힌 원이 나타납니다.

사용자에게 숫자만을 따라 보게 하십시오. 제대로 쳐다보면 숫자는 색깔이 변하면서 작아지며 사라지고, 다음 위치로 옮겨 갑니다. 총 6개의 점을 보고 나면 시선 보정이 완료됩니다.

<figure><img src="../../.gitbook/assets/image (583).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
자연스럽게 머리를 움직이며 점을 쳐다보아도 됩니다.
{% endhint %}

## 시선 보정 정확도 확인하기

시선보정이 완료되면, 시선보정 정확도를 확인하는 아래 화면이 나타납니다. 학생에게 숫자를 하나씩 쳐다보라고 지시하여 시선이 정확하게 맞는지 확인하십시오.

시선이 파란 원 밖으로 나갈 정도라면 다시 시선보정을 하는 것이 좋습니다.

화면의 어느 곳이든 클릭하면 정확도 확인하기가 종료됩니다.

<figure><img src="../../.gitbook/assets/image (602).png" alt=""><figcaption></figcaption></figure>

시선 보정을 확인하는 동안 화면을 쳐다보지 않거나, 시선이 잘 탐지되지 않으면 측정 정확도가 낮게 나오고, 이 경우 시선보정을 처음부터 다시 해야 합니다.

<figure><img src="../../.gitbook/assets/image (584).png" alt=""><figcaption></figcaption></figure>



{% hint style="info" %}
정확도를 확인하는 동안 화면만 바라보십시오. 시선 탐지율이 높지 않으면 다시 수행해야 합니다.
{% endhint %}
