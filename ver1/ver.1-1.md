# 자유글 문서 등록하기(ver.1)



메인 메뉴에서, 자유글 관리메뉴를 선택합니다.

<img src="../.gitbook/assets/image (475).png" alt="" data-size="original">

\[자유글 진단용 PDF관리] 리스트에서, \[새 PDF등록]버튼을 누릅니다.

<figure><img src="../.gitbook/assets/image (496).png" alt=""><figcaption></figcaption></figure>

\[PDF등록] 팝업창이 뜨면 자유글의 명칭, 분야, 레벨, 언어 등을 기재합니다.

![](<../.gitbook/assets/image (502).png>)

\[PDF파일선택]을 눌러 PDF파일을 선택하면, 새로운 창이 열리며 자유글이 보여집니다.

<figure><img src="../.gitbook/assets/image (524).png" alt=""><figcaption></figcaption></figure>

문서배율의 + - 버튼을 이용하 측정시 보여질 문서의 배율(크기)를 설정합니다.

<img src="../.gitbook/assets/image (510).png" alt="" data-size="original">

{% hint style="info" %}
좌우의 화살표를 이용하여 페이지를 이동할 수 있습니다.

배율은 최대 100%, 최소 40%까지만 가능합니다.
{% endhint %}

\[완료]를 눌러서 배율조정을 완료합니다. 언제든지 \[문서배율조정]버튼을 눌러 다시 조정할 수 있습니다.

\[저장]을 눌러 등록을 완료합니다.

{% hint style="info" %}
구독 종류에 따라 자유글을 등록할 수 있는 갯수가 제한될 수 있습니다. 자유글 갯수를 늘리려면 별도로 구매해야 할 수 있습니다.
{% endhint %}
