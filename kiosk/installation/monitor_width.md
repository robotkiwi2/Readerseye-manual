# 모니터 폭 설정하기

## 모니터폭  설정하기&#x20;

프로그램 설치 후, 자동으로  다음 화면으로 넘어가며, 최초 1회 \[디스플레이 세팅]을 해야 합니다.     &#x20;

<figure><img src="../../.gitbook/assets/image (255).png" alt=""><figcaption></figcaption></figure>

아래에 있는 두 개의 점선을 마우스로 드래그하여, 시선추적장비의 윗 선과 맞춥니다.

![](<../../.gitbook/assets/image (572).png>)

마우스로 두 개의 주황색 막대를 드래그하여  장비 윗면의 흰 선 위치와 맞추세요.       &#x20;

맞추었으면 \[적용] 버튼을 누릅니다. &#x20;

{% hint style="info" %}
이 작업은 모니터를 바꿀 때마다 수행해야 하며, 멀티모니터  사용시 사용 모니터가  바뀔 때도 다시 수행해야 합니다.       &#x20;
{% endhint %}
