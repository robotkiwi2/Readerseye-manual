# KIOSK(진단사이트) 로그인

연결 프로그램이 설치되었다면, 로그인을 합니다.

<figure><img src="../../.gitbook/assets/image (248).png" alt=""><figcaption></figcaption></figure>

관리자  사이트에서 키오스크의 비밀번호를 별도로 설정할 수 있습니다. 초기 비밀번호는 관리자 비밀번호와 같습니다.

## 상태 점검

로그인을 하면, 다음과 같은 화면이 진행되며 상태를 점검합니다. 만약 중간 단계에서 멈춘다면 문제를 해결하고 다시 진행해야 합니다.

<figure><img src="../../.gitbook/assets/image (254).png" alt=""><figcaption></figcaption></figure>

## 키오스크 설정

상태 점검이 완료되면, 다음과 같은 설정 화면이 보여집니다.

<figure><img src="../../.gitbook/assets/image (247).png" alt=""><figcaption></figcaption></figure>

### 설정 > 사용자 모드

* 등록모드 : 관리자가 미리 등록한 학생들만 사용할 수 있습니다. 학생이 스스로 진행하는  모드입니다. 학생별로 비밀번호가 필요합니다.
* 익명모드 : 도서관이나 체험관과 같이, 누구나 사용할 수 있는 모드입니다. 비밀번호가 필요없습니다.
* 교사모드 : 교사가 직접 학생을 진단하는 모드로, 편리하게 학생과 진단글 등을 선택할 수 있습니다. 비밀번호가 필요 없습니다.

### 테마

키오스크 화면의 디자인 테마를 설정합니다. 현재는 어린이 테마만 제공됩니다.

### 화면 보호기

키오스크의 화면보호기 동영상을 설정합니다. 현재는 제공되지 않습니다.
