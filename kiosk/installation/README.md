# 장치 설치

설치 동영상 : [https://youtu.be/kLHQPG2WFEI?si=A14\_v4-bRL02VfKq](https://youtu.be/kLHQPG2WFEI?si=A14_v4-bRL02VfKq)

## 필요 사항&#x20;

* 리더스아이 시선측정장비
* 윈도우즈10이 설치된 컴퓨터 (RAM 4G 이상)&#x20;
* 24인치 이하의 모니터 (1920 \* 1080 권장. Retina 고해상도 모니터는 사용하지 마십시오.)
* 또는 15인치 이상의 노트북
* 크롬 또는엣지 웹 브라우저
* 원활한 인터넷 접속

{% hint style="info" %}
노트북을 사용하더라도, 진단은 별도의 모니터를 사용하시는 것을 권장합니다.
{% endhint %}

## 장비의 구성&#x20;

* &#x20;시선추적장치 (USB연결)
* 모니터 부착용 철판 마운트

## 측정 환경

다음과 같은 환경에 진단 장소를 마련하십시오.

* 조용하고 안정적인 환경
* 직사광선이 들지 않는 환경&#x20;
* 앞뒤 폭이 깊은 책상
* 높이가 조절되는 책상 또는 의자 (권장)&#x20;
