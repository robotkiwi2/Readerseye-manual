# 장치 설치하기

## 장비 설치하기

설치 동영상 : [https://youtu.be/kLHQPG2WFEI?si=A14\_v4-bRL02VfKq](https://youtu.be/kLHQPG2WFEI?si=A14_v4-bRL02VfKq)

시선추적장비는 자석으로 모니터 하단에 부착됩니다.  이를 위하여  철판마운트를 모니터  하단에 먼저  부착해야  합니다.      &#x20;

<figure><img src="../../.gitbook/assets/image (573).png" alt=""><figcaption></figcaption></figure>

동봉된 철판마운트의 스티커 종이를  제거하세요.  &#x20;

<figure><img src="../../.gitbook/assets/image (275).png" alt=""><figcaption></figcaption></figure>

모니터 하단 베젤  중앙에 철판을 붙이세요. 최대한 스크린과 가까이 붙이되, 4mm정도 간격을 남겨두세요.

![](<../../.gitbook/assets/image (579).png>)

1. 철판 마운트를 모니터  하단 중앙에  수평으로  부착해 주십시오.  그 상태에서 1분 정도 누르시고, 5분 이상 기다려서 잘 부착되도록 하십시오.
2. 시선추적장비 뒷면의 홈과 마운트가  딱 맞게 부착하십시오.  철판과 자석이 정확하게  부착되어야 합니다.&#x20;
3. 시선추정장비의 USB 연결선을 컴퓨터에  연결하십시오.&#x20;
