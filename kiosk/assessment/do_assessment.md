# 읽기능력 진단 수행

## 진단 시작하기

시선보정까지 완료되었다면 아래 화면에서 \[진단시작] 버튼을 눌러 진단을 시작합니다.

## 텍스트 읽기&#x20;

화면에서 진단글이 제시됩니다. 제시된 텍스트를 말없이 읽으십시오.  다 읽으면 우측 아래의 \[문제 풀기 시작] 을 클릭하십시오. 읽는 동안 얼굴은 자연스럽게 움직여도 됩니다.

![읽기 화면](<../../.gitbook/assets/image (175).png>)

{% hint style="info" %}
&#x20;평소와 유사한 방식으로 읽도록 합니다.
{% endhint %}

{% hint style="info" %}
도중에 단축키 A를 눌러 실시간 시선을 확인할 수 있습니다. 이 때, 클릭은 작동하지 않습니다. 다시 A를 누르면 원래대로 돌아갑니다.
{% endhint %}

## 난이도 평가하기&#x20;

텍스트를 읽고 나면, 글의 난이도를 평가합니다.

![난이도 평가 화면](<../../.gitbook/assets/image (154).png>)

{% hint style="info" %}
텍스트 난이도 평가는 텍스트의 수준 조정에 활용되며, 읽기 능력 진단에 영향을 미치지 않습니다.
{% endhint %}

## 문제 풀기&#x20;

텍스트에 대한 질문에 답을 선택합니다. 질문은 3개에서 5개 정도 나옵니다. 어떤 질문은 텍스트 없이 풀어야 하고, 어떤 질문은 텍스트가 제시됩니다.

일정 점수를 얻지 못하면 제대로 읽지 않은 것으로 간주되어 진단이 취소되므로, 텍스트를 잘 읽고 성실하게, 가급적 빠르게 풀어야 합니다.
