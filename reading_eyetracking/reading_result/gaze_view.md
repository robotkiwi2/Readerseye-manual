# 시선 정보 분석 (시선 기록)

## 시선 정보 분석창

창이 열리면, 여러가지 결과 탭 중 \[텍스트 결과 탭]이 보여집니다. 좌측의 탭 제목을 눌러서 내용을 볼 수 있습니다.

{% hint style="info" %}
결과창의 URL 주소(링크)를 복사해서 전달하면, 어디서든 결과   창을 열어 볼 수 있습니다.
{% endhint %}

## 시선 기록보기

진단 결과 시선 기록을 보여줍니다. 좌측 하단의 \[재생버튼]을 눌러 읽은 과정 그대로 재생해 볼 수 있습니다.

수평시선 위치 차트 하단의 시간 슬라이더(빨간 막대)를 드래그 해서 시간을 설정할 수 있습니다.

## 수평시선위치 그래프

하단의 그래프는 \[시간에 따른 시선의 수평위치]를 보여줍니다. 가로축은 시간이며, 세로축은 시선의 수평(가로) 위치입니다.&#x20;

세로축의 0은 화면의 가장 좌측이며, 1.0은 화면의 가장 우측입니다. 즉, 시선이  시간이  흐름에  따라 수평위치가 어떻게 움직이며 흘러갔는지를, 파란색 선으로 보여줍니다.

<div data-full-width="true"><figure><img src="../../.gitbook/assets/image (628).png" alt=""><figcaption></figcaption></figure></div>

눈의 움직임을 명확하게 관찰하는 방법은,  시선의 가로 방향 움직임과 세로 방향 움직임을 분리하여 시간에 따라 보는 것입니다. 특히 가로 방향의 시선 움직임은 읽기 숙련도를 직관적으로 보여줍니다.&#x20;

글을 읽을 때 시선의 세로방향 움직임은 비교적 덜 중요하며, 가로(수평)방향의 움직임이 중요합니다. 그래서 이 그래프는 수평위치의 변화만을 나타내기 때문에 읽기행태를 파악하기에 편리합니다.

* Blue Line : 시선의 가로 방향 움직임(위치, 모니터 좌측부터 0\~1)
* Green Line : 눈 탐지가 안된 구간 (측정이 정상적이라면, 눈을 깜박인 구간으로 볼 수 있습니다.)

{% hint style="info" %}
읽기 유창성이 뛰어난 자는 반복적인 계단 모양의 가로 움직임이 나타납니다.
{% endhint %}

## 조작 패널&#x20;

좌측에 시선기록 보기를 조작할 수 있는 조작 패널이 있습니다.

<figure><img src="../../.gitbook/assets/image (358).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
조작패널의 상단 \[Drag]부분을 이용하여 위치를 옮길 수 있습니다.
{% endhint %}

### 텍스트 정보

읽은 텍스트의 정보를 보여줍니다.

텍스트는 2가지 언어(한국어, 영어)로.구분되며,   모든 텍스트는 글자수, 어절수, 문장수가 규정되어 있어, 읽기 행동을 진단할 때 활용됩니다.&#x20;

<figure><img src="../../.gitbook/assets/image (598).png" alt=""><figcaption></figcaption></figure>

### 지문/문제 선택 버튼&#x20;

<figure><img src="../../.gitbook/assets/image (337).png" alt=""><figcaption></figcaption></figure>

지문을 읽거나 문제들을 풀 때 시선을 보기 위하여 선택합니다. 키보드 1,2,3,4,5로 단축키를 이용할 수 있습니다.

하나의 텍스트는 읽기 task, 난이도 평가 task, 문제 풀이 task로 구성됩니다. task 버튼으로 읽기와 문제풀이 task에서의 시선 움직임을 선택해 볼 수 있습니다.&#x20;

선택 상자를 이용하거나, 단축키 (1,2,3...)을 이용하여 해당 텍스트의 다른 task 결과를 볼 수 있습니다.

![task(문제풀이) 하는 동안의 시선 사례](<../../.gitbook/assets/image (168).png>)

#### 문제 풀이 결과&#x20;

각 Task에서는 User가 선택한 Option과 답이 표시됩니다.

* User가 선택한 Option : 보라색&#x20;
* 답 Option : 초록색 테두리 &#x20;

{% hint style="info" %}
문제풀이 task에서는, 문제 영역과 핵심 정보 영역 위치가 표시됩니다. 해당 영역을 잘 보지 않았다면 탐색 효율성이 낮게 진단됩니다.
{% endhint %}

### 시선 위치 조정 버튼

<figure><img src="../../.gitbook/assets/image (338).png" alt=""><figcaption></figcaption></figure>

학생이 측정하는 동안 머리를 움직여서 시선 데이터가 전반적으로 상하좌우로 조금씩 밀려서 측정되었다고 판단된다면, 화살표 버튼을 이용하여 위치를 조정할 수 있습니다. 이는 키보드의 상하좌우 화살표 키를 단축키로 사용할 수 있습니다.

{% hint style="info" %}
조정된 위치는 영구적으로 저장되며, 다시 원래대로 되돌릴 수 있습니다.
{% endhint %}

조작패널을 이용해서 여러가지 조작이 가능합니다.

* 시선위치 조정 : 시선의 위치가 전체적으로 한쪽으로 치우쳐 측정되었을 경우, 각 방향 버튼을 이용하여 위치를 조정할 수 있습니다. (선생님이 조정한 경우에만 영구적으로 반영됩니다.)

<figure><img src="../../.gitbook/assets/image (344).png" alt=""><figcaption></figcaption></figure>

* 시선위치 늘리기 : 시선의 분포가 실제보다 좁거나 넓게 측정되었을 경우, 버튼들을 이용해서 가로 또는 세로 폭을 넓히거나 줄일 수 있습니다. (선생님이 조정한 경우에만 영구적으로 반영됩니다.)

### 설정

<figure><img src="../../.gitbook/assets/image (321).png" alt=""><figcaption></figcaption></figure>

Gaze Path 창에서 보여지는 정보를 원하는 데로 설정할 수 있습니다. 우측 하단의 톱니바퀴 모양의 아이콘을 클릭하십시오.

![Gaze Chart Option](<../../.gitbook/assets/image (163).png>)

* 시선 Gaze : 측정된 시선의 위치 빨간색 원으로 보여줍니다. (hot key : G)
* 시선 경로 Gaze line : 시선을 빨간색 선으로 연결해 줍니다. (hot key : K)
* 시선 크기 : 시선 원의 크기 배율을 정합니다.
* 응시 Fixation : 집결한 시선들을 응시로 구분하여 파란색 원으로 보여줍니다. (hot key : F)
* 응시 크기 : 응시 원의 크기 배율을 정합니다.
* 응시 경로 Fixation Line : 응시들을 파란색 선으로 연결해 줍니다. (hot key : L)
* 이동 분류 Saccade Type : 응시 간 이동을 분류하여 색상으로 표현합니다. (hot key : S)
* 응시 순서  fixation order : 응시의 순서를 숫자로 보여줍니다. (hot key : N)
* 핵심 영역 AOI : 문제 풀이시 핵심정보 영역의 위치를 보여줍니다. (hot key : A)

![시선의 이동분류 보기(단축키 : S)로 시선이동을 분류한 모습](<../../.gitbook/assets/image (103).png>)

{% hint style="info" %}
시선의 분석은 주로 응시 fixation 과 이동 saccade 를 활용합니다.
{% endhint %}

{% hint style="info" %}
단축키를 사용하시면 쉽고 빠르게 보기옵션을 변경할 수 있습니다.
{% endhint %}
