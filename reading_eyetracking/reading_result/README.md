# 읽기 진단 결과 보기

## 진단 결과 열기

시선 읽기 진단이 종료되면, 해당 학생의 \[시선읽기진단]탭 화면에서 새로운 진단결과 카드가 생깁니다.

<div data-full-width="true"><figure><img src="../../.gitbook/assets/image (377).png" alt=""><figcaption></figcaption></figure></div>

### 읽기 진단 기록 카드 선택

진단기록 카드를 클릭하면, 진단 결과 창이 열립니다.

<figure><img src="../../.gitbook/assets/image (421).png" alt=""><figcaption></figcaption></figure>

### 결과 보기 선택창

<figure><img src="../../.gitbook/assets/image (724).png" alt=""><figcaption></figcaption></figure>

진단기록 카드를 클릭하면, 위와 같은 창이 열립니다. 상단에는 진단에 대한 정보가 표시되며, 하단의 버튼들은 다음과 같습니다.

* 내  결과보기 : 결과가 새로운 창으로 열립니다. 읽기결과 보기 창이 열린 상태입니다.
* 전체 베스트 결과창 열기 : 이 진단 글을 읽은 전체 학생 중, 가장 진단점수가 높았던 학생의 결과창이 열립니다. 이 결과창을 나란히 놓고 비교해 볼 수 있습니다.
* 기관내 베스트 결과창 열기 : 이 진단 글을 읽은 같은 기관 소속 학생 중, 가장 진단점수가 높았던 학생의 결과창이 열립니다.&#x20;
* 결과 링크 생성 : 결과를 전달할 수 있는 인터넷 링크(URL)을 보여줍니다. \[신버전 결과창 열기]를 눌러 열린 창의 주소와 같습니다.
* 훈련 추천 : 읽기 진단 결과를 바탕으로 적절한 훈련을 추천해 줍니다.(AI기반)

## 진단 결과창의 구조

'진단 결과창'의 메뉴 중 \[시선정보 분석] 메뉴에서 \[측정 결과 보기] 버튼을 누르면 '시선 정보 분석 창'으로 바뀌며, '시선정보 분석창'을 닫으면 다시 '진단 결과창'이 됩니다.

{% hint style="info" %}
처음에는 '시선정보 분석창' 상태로 결과창이 열립니다.
{% endhint %}
