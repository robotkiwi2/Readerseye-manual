# 종합 분석

진단 결과의  '종합분석'탭에서는 진단한 텍스트 세트에 포함 모든 텍스트 읽기 결과를 종합하여 분석을 제공합니다.

<figure><img src="../../.gitbook/assets/image (362).png" alt=""><figcaption></figcaption></figure>

## 종합 읽기 점수 분포

<figure><img src="../../.gitbook/assets/image (359).png" alt=""><figcaption></figcaption></figure>

* 종합읽기 점수는 읽기 유창성 및 문제 탐색, 문제 풀이 결과를 종합하여 산출합니다.
* 진단 점수 분포를 통해, 해당 연령대와 언어에 대한 나의 점수 위치를 비교할 수 있습니다.
* 초록색 분포선은 우리 기관(학원, 학교 등)의  또래  점수 분포이고, 파란색 분포선은 전국의 전체 또래 점수 분포입니다.
* 나의 점수는 빨간색 수직선으로 표시되며, 전체, 기관 또는 조직에서의 백분위수(percentile)이 표시됩니다.

## 독서가 유형&#x20;



읽는 패턴에 따라 분류한 독자의 유형이며, 대략적인 스타일을 알려줍니다.&#x20;

이 분류는 읽기 특성의 7가지 속성을 기반으로 한 군집분석(clustering)을 통해 이루어지며, 가장 유사한 그룹으로 분류하는 것이므로 절대적인 특성이라고 볼 수 없습니다.

<figure><img src="../../.gitbook/assets/image (360).png" alt=""><figcaption></figcaption></figure>

|     타입    |      비     | 특                                                                              |
| :-------: | :--------: | ------------------------------------------------------------------------------ |
|  번개같은 토끼  | 11%        | 빠르지만 전체를 착실하게 읽지 않고, 문제도 너무 빠르게 풀어서 많이 틀리는 편입니다. 착실하게 글을 차근차근 읽도록 노력하세요.       |
|  느릿느릿 거북이 |     6%     | 차근차근 착실하게 읽지만 읽기와 문제풀이가 많이 느립니다. 글이 너무 어렵게 느껴질 수 있으니 쉬운 글을 읽으세요                |
|  바람직한 독서가 |     47%    | 유창하고 자연스럽게 글을 읽으며, 글에 대한 이해도 좋습니다. 조금 더 어려운 글을 읽어도 좋습니다.                       |
|  기계적인 반복자 |     22%    | 글을 읽는 시선은 유창하고 자연스럽지만, 글 내용을 이해하지 못하고 있습니다. 의미를 생각하면서 읽는 연습을 하세요               |
| 체력약한 하루살이 |     5%     | 글에 집중하지 못하여 유창성이 떨어지며 이로 인해 글을 이해하기도 어렵습니다. 더 쉬운 글을 많이 읽을 필요가 있습니다.            |
|  마이웨이 탐색가 |     8%     | 글을 크게 이동하며 여기저기 읽으면서도, 문제는 잘 풀어냅니다. 상식과 탐색만으로는 좋은 읽기라고 할 수 없으니, 차분하게 읽도록 노력하세요 |

{% hint style="info" %}
독자 유형별로 문제점 및 개선 방향을 지도할 수 있습니다.
{% endhint %}
