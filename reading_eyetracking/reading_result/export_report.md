# 보고서 출력 (PDF 다운)

## 보고서 출력 하기&#x20;

<figure><img src="../../.gitbook/assets/image (331).png" alt=""><figcaption></figcaption></figure>

메뉴에서 \[pdf다운]을 누르면, A4 출력용 보고서를 다운로드 받을 수 있습니다.

보고서는  pdf형식으로 작성되며, 파일은  '다운로드'폴더로 받아집니다.

{% hint style="info" %}
보고서 출력은 네트워크 상태 등에 따라 몇 분 정도 소요될 수 있습니다.
{% endhint %}
