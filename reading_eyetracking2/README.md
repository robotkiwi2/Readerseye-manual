# 읽기진단2 결과 보기

**읽기진단2**는 학생이 지문을 읽고 문제를 푸는 동안의 시선(눈 움직임)을 측정해서, 읽기 수행을 점수와 유형, 소견, 이슈로 보여 주는 진단입니다. 기존 \[읽기진단]과는 별개의 진단이며, 두 진단이 나란히 제공될 수 있습니다.

{% hint style="info" %}
\[읽기진단2] 탭은 기관의 탭 설정에서 켠 경우에만 표시됩니다. 탭이 보이지 않으면 기관 설정을 확인하세요.
{% endhint %}

## 결과를 보는 두 가지 방법

| 방법 | 대상 | 볼 수 있는 내용 |
|---|---|---|
| [관리자 페이지에서 보기](result_admin.md) | 교사, 기관 관리자 | 한 학생의 소견, 상태, 이슈와 진단 기록. 그룹이나 기관 단위의 점수 추이와 학생 위치 |
| [진단 보고서에서 보기](result_report.md) | 교사, 학부모 | 한 회차의 결과를 담은 보고서. 링크로 열 수 있어 학부모에게 전달할 수 있습니다. |

* 학생은 키오스크에서 진단만 하며, 결과 화면은 교사와 관리자가 앱에서 확인합니다.
* 학부모는 교사가 만든 링크로 보고서를 봅니다.

## 알아 두세요

{% hint style="warning" %}
읽기진단2는 눈 움직임으로 **읽기 수행을 관찰하는 도구**입니다. 읽기가 어려운 원인을 가려내거나 진단명을 내리는 검사가 아닙니다. 결과에 나오는 설명은 관찰된 행동을 바탕으로 한 것이며, 다른 이유가 있을 수 있습니다.
{% endhint %}

* **점수는 두 가지**입니다. 글을 읽는 모습을 나타내는 **읽기 유창성**과, 문제를 푸는 모습을 나타내는 **문제풀이**입니다.
* 점수는 학생의 나이나 글의 레벨과 상관없이 **하나의 기준**으로 계산합니다. 그래서 성인이 아이보다 높은 점수를 받는 것이 자연스럽습니다.
* 등급은 **우수, 보통, 주의, 위험**으로 표시됩니다.
* 등급과 상위 %는 아직 기준 데이터를 모으는 중이어서 **추정**으로 표시됩니다. 기준 데이터가 쌓이면 점수는 그대로이고 등급과 상위 %만 더 정확해집니다.
