# 진단글 관리하기

## 진단글 추가하기

읽기능력 진단에 사용할 지문(글)과 문제로 이루어집니다. 진단글을 만들고 활성화해야 사용할 수 있습니다.

![](<../../.gitbook/assets/image (188).png>)

{% hint style="info" %}
텍스트는 만든 조직에 속해 있는 Agency만 진단에 사용할 수 있습니다.

지문을 만든 조직관리자만 지문을 수정하거나 삭제할 수 있습니다.
{% endhint %}

{% hint style="warning" %}
텍스트를 만들 때는 저작권 문제가 없는지 검토하시기 바랍니다.&#x20;
{% endhint %}

### 지문 입력하기

우측의 지문 입력에 글을 쓰거나, 붙여 넣기 하여 글을 입력합니다. 글자 폰트 크기나 자간 등을 조절하여 화면에서 읽기 좋은 상태로 편집하십시오.

{% hint style="info" %}
줄 바꿈 등을 정확하게 진단하기 위해서는, 가급적 줄이 짧게 끝나지 않고 2/3이상 채워지도록 작성하는 것이 좋습니다.
{% endhint %}

![좋은 사례 : 각 글줄이 거의 글자로 채워져  있음](<../../.gitbook/assets/image (136).png>)

![안 좋은 사례 : 두번째 글 줄이 대부분 텅 빈 상태로 남아 있음](<../../.gitbook/assets/image (127).png>)

{% hint style="warning" %}
인터넷 등에서 복사해 온 글은 글자 크기나 간격 등 편집이 잘 안될 수 있습니다. 이 경우, 글을 메모장 등에 저장한 후 다시 복사하여 붙 보십시오.
{% endhint %}

### 문제 입력하기

문제는 시선추적으로 읽기 진단을 정확히 수행하기 위하여 학생이 **성실하게 지문을 읽도록 유도**하기 위한목적입니다. 그러므로 학생의 추론이나 비판적 언어능력을 측정한다기 보다는, 글을 성실하게 읽었다면 풀 수 있는 **사실적 이해**를 묻는 것이 좋습니다.

문제의 정답 풀이시간은 '사실적 이해' 점수에 반영됩니다.

{% hint style="info" %}
텍스트당 문제는 최대 5개까지 제출할 수 있습니다.
{% endhint %}

![](<../../.gitbook/assets/image (200).png>)

#### 문제 항목 입력하기

문제 추가 버튼을 눌러서 새로운 문제를 입력하십시오.

{% hint style="info" %}
기본으로 입력되어 있는 첫번째 난이도 문제 (이 글은 읽기 쉬웠나요?)는 모든 텍스트에 공통으로 수행되는 문제이므로, 삭제하거나 수정할 수 없습니다.
{% endhint %}

#### 보기 항목 입력하기

문제 항목에 대해 선택 가능한 보기 항목들을 추가하십시오. 보기 항목은 최대 5개까지 입력할 수 있으며, 그 중 하나는 정답으로 선택되어야 합니다.

#### 지문 공개 선택하기&#x20;

지문 공개를 선택하면, 문제를 풀 때 지문이 옆에 함께 보여집니다. 기억만으로 풀기 어렵거나, 지문을 탐색하면서 푸는 것이 필요하다고 생각되면 선택하십시오.

#### 핵심영역 설정하기&#x20;

지문을 보면서 푸는 문제의 경우, 꼭 봐야 하는 중요한 영역을 핵심영역으로 지정할 수 있습니다. 풀이시 이 영역을 얼마나 보는지가 ‘핵심영역 체류율＇로 측정됩니다.

![](<../../.gitbook/assets/image (138).png>)

* 핵심영역 추가 버튼을 누른 후, 마우스를 드래그 하여 해당 문제 풀이에 중요한 단어나 문장이 있는 영역을 선택합니다.
* 좌측 제목 영역에 핵심영역의 이름을 입력합니다.
* 좌측 상단의 영역추가 버튼을 눌러서 완료합니다.
* 핵심영역 임시보기 버튼을 누르고 있는 동안, 설정한 핵심영역을 확인할 수 있습니다.

![](<../../.gitbook/assets/image (100).png>)

{% hint style="info" %}
핵심영역은 지문을 공개하는 문제에서만 설정할 수 있습니다.
{% endhint %}

### 진단 정보 설정하기

![](<../../.gitbook/assets/image (151).png>)

#### 기본 항목 설정하기

* 제목 : 텍스트의 특징을 명확히 드러내도록 작성해 주십시오.
* 언어 : 텍스트의 주요 언어를 선택하십시오.
* 레벨 : 이 텍스트를 읽고 풀이하기에 적당하다고 생각되는 자의 만 나이를 선택하십시오.
* 분야 : 이 지문 내용의 분야를 문학, 인문사회, 과학기술, 기타 중에서 선택해 주십시오.

#### 정량 정보(글자수) 자동 계산하기

우측의 **글자 수 자동계산** 버튼을 누르면, 지문의 정량정보(글자수, 단어수, 문장수, 줄수)를 자동으로 계산해 줍니다. 자동계산 결과가 정확하지 않을 경우, 수동으로 수치를 수정할 수 있습니다.
