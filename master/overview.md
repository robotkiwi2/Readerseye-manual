# 리더스아이의 구성

리더스아이는 **웹기반**으로, 시선측정이 아닌 모든 작업은 어느 컴퓨터나 스마트폰에서도 자유롭게 접속하여 수행할 수 있습니다.

## 누가, 어떻게 사용하나요?

* 선생님(관리자)는 자신의 업무용 또는 개인용 컴퓨터에서 로그인하여 학생을 관리하거나 결과를 조회할 수 있습니다.&#x20;
* 학생은 시선추적장치가 설치된 **진단용 컴퓨터(키오스크)**&#xC5D0;서 ‘시선읽기진단’을 할 수 있습니다.&#x20;
* 학생은 자신의 컴퓨터/타블렛/스마트폰으로 로그인하여 자신의 결과를 보거나, **인지훈련**(Web Training)을 수행할 수 있습니다.&#x20;
* 시선읽기진단  결과, 훈련수행 보고서는 메일이나 문자로 링크 형태로 학부모에게 제공될 수 있으며, 별도의 로그인 없이 바로 볼 수 있습니다.

## 세 가지 웹 사이트를 사용합니다.

리더스아이를 운용하기 위해서는 다음의 세가지 웹 사이트를 사용하게 됩니다. 자세한 내용은 별도로 설명합니다.

### 관리자 사이트 : app.readerseye.com

* 관리자(선생님)이 가장 빈번하게 사용하는 사이트입니다. 학생을 관리하고, 진단 결과를 조회하고, 트레이닝을 점검하거나 할당할 수 있습니다.
* PC화면(1920x1080)에 최적화되어 있습니다.

### 학생용 사이트 : www.eyestudent.com

* 학생들이 사용하는 사이트입니다. 자신의 진단기록을 확인하고, 인지훈련을수행할 수 있습니다.
* 타블렛/스마트폰 화면에 최적화되어 있습니다.

### 진단 사이트 : kiosk.eyestudent.com

* 시선을 측정하는 작업(읽기능력 진단, 자유글 측정, 인지훈련,  눈훈련 등)을 수행할 때 사용하는 사이트입니다.
* 이 사이트에서 시선측정을 하기 위해서는 시선추적장치가 설치되어 있어야 합니다.

{% hint style="info" %}
리더스아이 안내사이트(www.readerseye.com)에서, 세 사이트들의 링크가 있습니다.
{% endhint %}
